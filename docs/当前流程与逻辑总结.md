# 规划转提报工具 — 当前流程与逻辑总结

> 生成时间：2026-05-20

## 一、整体架构

```
用户 Excel 文件
      ↓
  excel_io（解析 + 合并单元格拆分 + 区域裁剪）
      ↓
  UI（指定 Sheet 类型、执行范围、执行方向）
      ↓
  ConversionEngine（按 JSON 模板逐行转换）
      ↓
  预览 / 导出 Excel + 异常清单
```

| 模块 | 文件 | 职责 |
|------|------|------|
| 入口 | `__main__.py` | 定位项目根目录，启动 GUI |
| UI | `ui/main_window.py` | 模板选择、上传、配置、执行、预览、导出 |
| 模板 | `template_loader.py` | 加载/解析 JSON 模板 |
| 数据模型 | `models.py` | InputSpec / OutputSpec / FieldSpec 等 |
| Excel I/O | `excel_io.py` | 读 workbook、拆分合并单元格、区域转表、写结果 |
| 转换引擎 | `engine.py` | 过滤、字段映射、查表、异常收集 |

---

## 二、用户操作流程（GUI）

1. **选择转换模板** — 从 `templates/*.json` 加载
2. **批量上传 Excel** — 支持 `.xlsx` / `.xlsm`，解析所有 sheet
3. **配置每个 Sheet** — 在列表中为每个 sheet 指定类型（规划表、商品清单等）
4. **设置执行区域** — 起始单元格（默认 A1）、结束单元格（默认最后一个非空区域）、逐行/逐列
5. **执行转换** — 调用引擎生成结果表
6. **预览结果** — Tab 页展示各输出表及异常清单（最多 500 行）
7. **导出结果** — 按模板定义的 file_name 写入 Excel

## 三、数据处理逻辑

### 3.1 Excel 解析（`parse_workbook_sheets`）

- 用 openpyxl 读取原始单元格矩阵（`data_only=True`）
- 按规则拆分合并单元格：
  - **单行横向合并** → 每个单元格填充原值
  - **单列纵向合并** → 拆分后仅最后一个单元格保留原值，其余置空
  - **多行多列合并** → 不自动处理，记录提示信息
- 返回 `ParsedSheet` 列表（含 merge_notes）

### 3.2 区域转表（`table_from_range`）

- 按用户指定的起始/结束单元格裁剪区域
- **逐行模式（row）**：第一行作为字段名，后续每行一条记录
- **逐列模式（column）**：转置后第一行作为字段名，后续每列一条记录
- 空行自动丢弃；空表头命名为「未命名字段N」

### 3.3 Sheet 类型聚合（`_collect_typed_tables`）

- 用户为每个 sheet 指定一个「类型」角色
- 同类型多个 sheet **后者覆盖前者**（当前未做合并）
- 至少需指定一个 sheet 类型才能执行

## 四、模板规则（JSON）

### 4.1 结构

```json
{
  "name": "模板名",
  "version": "0.2.0",
  "inputs": [{ "key", "label", "required" }],
  "outputs": [{
    "key", "label", "file_name", "sheet_name",
    "primary_input", "primary_sheet",
    "filters": [...],
    "fields": [{ "name", "source", "required" }]
  }]
}
```

### 4.2 示例模板输出表

| 输出表 | 主输入 | 说明 |
|--------|--------|------|
| 活动汇总表 | 规划表 | 活动基本信息 + 正则解析满减 |
| 活动对应UPC表 | 规划表 | 商品信息 + 查商品清单补 UPC/指导价 |

### 4.3 字段来源类型（`source.type`）

| 类型 | 说明 |
|------|------|
| `direct` | 直接映射源列 |
| `constant` | 固定值 |
| `concat` | 多段拼接（支持嵌套 source） |
| `regex_extract` | 正则提取指定分组 |
| `lookup` | 从辅助表按列匹配查值 |
| `manual` | 标记需人工补充，写入异常清单 |

### 4.4 行过滤规则（`filters`）

支持运算符：`empty` / `not_empty` / `equals` / `not_equals` / `contains` / `not_contains` / `regex`

- 命中且 `action=skip` → 跳过该行，记录 info 级异常

## 五、转换引擎核心逻辑

```
对每个 output：
  1. 取 primary_input 对应的主表
  2. 逐行遍历：
     a. 检查 filters → 命中则 skip
     b. 对每个 field 按 source.type 解析值
     c. required 字段为空 → 记录 warning
  3. 汇总为 DataFrame
  4. 所有 issues 汇总为「异常清单」表
```

### 查表逻辑（lookup）

- 左值 = 主表当前行的 `left_column`
- 右表 = `input` 指定类型的 sheet 表
- 按 `right_column` 字符串精确匹配
- 无匹配 → warning；多匹配 → warning 并取第一条

## 六、异常清单

| 级别 | 典型场景 |
|------|----------|
| error | 缺少必填输入、找不到主表/查表、正则语法错误 |
| warning | 必填字段为空、查表无匹配/多匹配、正则未命中 |
| info | 行被 filter 跳过 |

## 七、当前边界与限制

**已实现：**
- 多文件多 sheet 上传与类型指定
- 合并单元格基础拆分
- 逐行/逐列执行
- 6 种字段来源 + 行过滤
- 预览与导出

**尚未实现：**
- 横向勾选表自动转纵向
- 一行输入展开多行输出
- 预算复杂分摊
- 可视化模板设计器
- 同类型多 sheet 合并策略
- 模板中已定义但未在示例中使用的输入（预算分配表、门店清单等匹配逻辑）
