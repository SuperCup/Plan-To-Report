## P3：DeepSeek 辅助

- 向导步骤 ④ 可勾选「启用 DeepSeek 辅助」
- API Key / 模型 / 接口：向导步骤 ④ 填写，点「保存 DeepSeek 配置」写入 `config/app_settings.json`
- 也可直接编辑 `config/app_settings.json`（参考 `config/app_settings.example.json`）
- 环境变量 `DEEPSEEK_API_KEY` 仅在配置文件中 Key 为空时作为兜底
- 触发场景：
  - 活动机制规则拆分只有 1 段，但文本含 `①②`、多个「满 xx」等 → AI 拆段
  - 合写口味 token 无法匹配到商品行 → AI 返回口味列表
- 失败时写入异常清单 warning，**回退规则解析**

## P4：多行包装 + 统一联调

### 多行包装单元格

活动列单元格示例：

```text
藤/麻
开心桶
```

解析为：口味 token `藤`、`麻` × 规格行 `开心桶` 下的口味商品行。

### 统一入口

```python
from plan_to_report.plan_pipeline import PlanConversionInput, run_plan_conversion

output = run_plan_conversion(PlanConversionInput(...))
# output.summary_table / output.upc_table / output.issues
```

GUI「执行转换」已改为调用 `run_plan_conversion`。
